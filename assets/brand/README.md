# Smart Attendance brand assets

The mark combines three QR-inspired finder squares with a mint checkmark. It represents scanning and a recorded check-in; it is decorative and is not a scannable QR code.

| Asset | Use |
| --- | --- |
| `logo.svg` | Editable vector master with a transparent area outside the rounded tile. |
| `logo.png` | 512 × 512 transparent app artwork used by `BrandLogo`. |
| `app-icon.png` | 1024 × 1024 opaque icon for Expo/iOS. |
| `adaptive-icon.png` | 1024 × 1024 transparent Android foreground, with the mark centered inside the safe region. |
| `splash.png` | 512 × 512 splash artwork on deep blue. |
| `favicon.png` | 64 × 64 web favicon. |
| `portfolio-cover.svg` / `.png` | Editable and raster 1280 × 640 project covers for GitHub and portfolio use. |

Colors: deep blue `#172554`, white `#FFFFFF`, mint `#6EE7B7`. Keep the mark square and preserve its padding. The supplied PNGs are raster exports of the vector geometry. When changing the mark, update the cover and raster exports together.
